# ClipboardProtector 剩余工作清单

> 当前项目仍处于开发阶段。单进程保护入口允许选择任意兼容桌面进程，但注入仍可能影响目标稳定性；真实剪贴板/GUI 端到端优先使用 Windows Sandbox，全局稳定性、重启、自启和安装卸载仍需带快照的普通 VM。三层策略不互相替代，也不允许在物理主机启用全局 Hook。
>
> 勾选项表示已有代码审查、构建或对应层级的运行证据；未勾选项仍需按其说明完成，单进程 Sandbox 结果不能替代全局多进程、重启和故障压力验收。
